# Libr4 IDE - Golden Stack Edition

Высокопроизводительная облачная среда разработки с изолированным выполнением кода.

## Архитектура

**F# (Domain)**: Стейт-машина состояний агента. Гарантирует отсутствие некорректных переходов.

**C# (Application)**: Отказоустойчивый оркестратор с поддержкой JWT, SignalR, транзакций и кэширования.

**Rust (Sandbox)**: Изолированная песочница (Obscura) для безопасного исполнения пользовательского кода.

**PostgreSQL**: Хранение состояний и событий с автоматической политикой очистки (TTL).

## Технологии

- **Real-time**: SignalR (WebSockets) с автоматической синхронизацией
- **Безопасность**: JWT Auth, Code Guardian (валидация кода), RowVersion (Optimistic Concurrency)
- **Производительность**: SHA-256 Memoization Cache (экономия ресурсов до 90%)
- **Мониторинг**: Prometheus + Grafana

## Запуск

```bash
docker-compose -f docker-compose.ide.yml up --build
```

## Доступные сервисы

- **API**: http://localhost:5000
- **Monitoring**: http://localhost:3000 (Grafana)
- **Database**: localhost:5432

## Компоненты

### SignalR Hub
- `AgentHub` - трансляция событий агентов в реальном времени
- JWT авторизация через QueryString для WebSockets
- Проверка владения данными через `OwnerId`
- Начальная синхронизация состояния для предотвращения мерцания UI

### Code Guardian
- Валидация длины кода (макс. 50KB)
- Проверка на запрещенные паттерны (`std::fs`, `unsafe`, `/etc/passwd`)
- Базовая проверка структуры (`fn main()` для Rust)
- Мгновенный фидбек через SignalR

### Execution Cache
- SHA-256 хэширование кода и языка для мемоизации
- TTL 1 час для автоматической очистки
- Кэшируются только успешные результаты
- Снижение нагрузки на Rust песочницу до 90%

### Resilient Orchestrator
- Транзакционное выполнение задач
- Обработка сетевых сбоев с записью состояния
- Интеграция с SignalR для реальных уведомлений
- Оптимистическая блокировка через RowVersion
